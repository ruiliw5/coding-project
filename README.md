#### 💼 Java Invoicer Application

**Completed:** Spring 2025 (UCI – ICS 45J Lab Project)

This is a desktop invoicing system built in Java using Swing. The application allows users to generate complete invoices with dynamic calculations and an interactive user interface.

---

#### 🔧 Features

##### Customer Information Panel

- Bill-To / Ship-To fields  
- State selector with automatic tax calculation  
- Premium customer toggle  
- Coupon options (0–20%)

##### Invoice & Item Management

- “Add Item” modal dialog for adding items (description, price, quantity)  
- Real-time updates to subtotal, tax, discounts, and final total  
- Automatic due-date generation  
- Input validation and formatted currency display  

##### Backend Logic

- Object-oriented classes (e.g., `Invoice`, `Item`, `InvoiceCalculator`)  
- Event-driven recalculation when UI values change  
- Modular implementation of state tax rules and coupon logic  

##### 🧪 Testing

- Tests for total and tax calculations  
- Tests for coupon effects and edge cases  
- Verifies that UI actions trigger correct updates
