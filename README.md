#### Player Value Analysis Across Seasons

This project analyzes player performance and value across 11 seasons (Season 0–10). Each season contains ~50 players with information on:

- Demographics: ID, location, gender, age  
- Sport context: sport type, season  
- Performance/health: training hours (biweekly), number of injuries  
- Economic outcome: player market value  

Using Season 0 as a baseline, the project:
- Explores how player value relates to age, training hours, and injuries  
- Compares how player value changes over time for a sample of players  
- Examines average player value trends across seasons by location, sport, and gender
